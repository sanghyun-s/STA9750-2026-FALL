Mini-Project #1: Exploring Netflix viewing data

** Based on Netflix’s semi-annual “What We Watched” data, this mini-project explores which types of programming capture the majority of the platform’s watch time. The analysis examines inline values, extraordinary viewership outliers, and their associated statistical variables. The final output will be a corporate strategy memo addressed to Netflix’s content leadership analyzing the contrast between major blockbusters and the long tail of smaller titles. Specifically, the memo will examine the variation of viewership by using period-end and release-date columns to calculate a days_available metric, examining whether titles released near the end of a reporting period show higher viewing intensity despite a shorter availability window.**

Data Acquisition

** Data acquisition is based on Netflix’s “What We Watched” reports spanning 2023 H1 through 2026 H1. The Quarto (.qmd) file automatically executes the load_Netflix_data function, ensuring the latest datasets are loaded without requiring manual downloads or re-runs. **

Show code 
load_netflix_data <- function(){
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)

  data_dir <- path("data", "mp01")

  if(!dir_exists(data_dir)){
    dir_create(data_dir, recurse = TRUE)
  }

  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )

  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    return(local)
  }

  NETFLIX_URLS |>
    map(read_html) |>
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |>
    map_chr(html_attr, "href") |>
    enframe("period", "url") |>
    mutate(path = path(data_dir, paste0(period, ".xlsx")),
           path = map2(url, path, download_if_needed),
           data = map(path, read_excel, skip = 3, na = "*"),
           data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |>
    select(-url, -path) |>
    mutate(year = str_sub(period, 1, 4),
           half = str_sub(period, start = 6),
           period_start = make_date(year, if_else(half == 1, 1, 7), 1),
           period_end   = make_date(year, if_else(half == 1, 6, 12), if_else(half == 1, 30, 31))) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"),
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime    = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm = TRUE)),
           .by     = Title,
           Title   = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title   = str_remove(Title, " // .*"),
           Title   = str_remove(Title, "[^[:ascii:]].*"),
           Title   = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year,
           period,
           period_start,
           period_end,
           Title,
           -half,
           Runtime,
           Views,
           `Hours Viewed`,
           `Release Date`,
           `Available Globally?`,
           live_event) |>
    # Task 2: tidy column names
    rename(title              = Title,
           runtime            = Runtime,
           views              = Views,
           hours_viewed       = `Hours Viewed`,
           release_date       = `Release Date`,
           available_globally = `Available Globally?`) |>
    # Task 3: correct column types
    mutate(year               = as.integer(year),
           available_globally = available_globally == "Yes")
}

NETFLIX_DATA <- load_netflix_data()

Initial Data Exploration

** By examining the dataset’s structure, we can get a clear picture of Netflix’s viewing patterns over 3.5 years. The categorical and date variables (chr, date, and int) identify each of the 61,892 observations and place them on an exact timeline. The numerical variables (dbl) measure total watch hours, while runtime and release dates provide additional context for evaluating viewer engagement over time. Finally, the logical variables (lgl) help distinguish between live broadcasts and global releases, making it easier to analyze different segments of Netflix’s content library. **
